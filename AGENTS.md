# AGENTS.md

Этот репозиторий — ML-сервис (FastAPI + gRPC) с миграциями Alembic, линтингом Ruff и тестами Pytest.

## Цель агента
Реализовывать изменения в коде по подходу Plan & Act:
1) сначала план (в отдельном markdown-файле в корне)
2) реализация по плану маленькими шагами
3) обязательный запуск линтеров и тестов
4) обновление документации (API.md) и CHANGELOG.md

## Как работать с репозиторием
- Всегда начинай с чтения: README.md, pyproject.toml, ml_service/api_rest.py, ml_service/services.py, ml_service/schemas.py, dashboard/app.py
- Если меняешь API: обновляй схемы pydantic, роуты FastAPI, и добавляй тесты.
- Не добавляй новые тяжелые зависимости без необходимости.
- Не ломай существующие эндпоинты: любые изменения должны быть обратно-совместимыми или сопровождаться миграциями/описанием в CHANGELOG.

## Команды, которые ОБЯЗАТЕЛЬНО запускать
Запускать из корня репозитория.

### Линтер/форматтер
- Форматирование:
  - `poetry run ruff format .`
- Проверки:
  - `poetry run ruff check .`

### Тесты
- `poetry run pytest -q`

Если тесты падают — исправляй до зелёного состояния.

## Стиль изменений
- Минимальные правки, без лишнего рефакторинга.
- Любой новый функционал должен иметь:
  - схемы (ml_service/schemas.py)
  - обработчик (ml_service/api_rest.py)
  - бизнес-логику (ml_service/services.py или отдельный модуль)
  - тест(ы)
  - запись в CHANGELOG.md
  - описание в API.md

## Документация
- API.md должен описывать:
  - как запустить сервис
  - базовый URL
  - ключевые эндпоинты REST и gRPC
  - примеры запросов curl
- CHANGELOG.md: фиксируй изменения по датам, кратко и по делу.
